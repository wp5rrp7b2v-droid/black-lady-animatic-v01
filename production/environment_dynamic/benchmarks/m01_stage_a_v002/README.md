## 3. 通过条件

**阶段 A1（人工精确标注）**：
1. 每个可见烛火的真实中心及核心轮廓经过人工核验；同一烛台多根火焰共享正确的 fixture ID，但每根火焰独立记录核心。
2. 逐帧独立核对人物、衣服、头发、脸部、遮挡和漏检；被遮挡火焰应标记不可见。
3. 对 N24 漏检和 NEW-01 歧义明确处理为正确标注或不可判定，禁止用猜测默认“通过”。
4. 对 N17 验证视频内光源出现/消失的时间点；对日光负样本验证错误激活。
5. 人工审核签收后生成单独不可变的标注数据版本；**绝不原地把机器候选改名为 Ground Truth**。

**阶段 A2（基准测评）**：
对已冻结的 Ground Truth 计算逐火焰定位误差、漏检/误检、人物漏保护率、遮罩越界、无烛火误触发与时域稳定性。原始视频和 33 张候选遮罩可复现并对照 SHA。

S02-B 通过也不是可复用引擎完成：跨场景未参与调参的独立盲测，是后续产品验收必需门禁。不得在 A1 前把本 V002 数据用作自动通过标准，也不得解锁 M01 batch HOLD。
