# M01 V002｜Stage A 烛火引擎标准验证集

**目的**：为可跨镜头、跨场景复用的烛火引擎建立真实可复核的标注基准。S02-B 是训练/验证首样本，不是最终复用验收。  
**状态**：A0 数据构建进行中；A1 人工定位和人物保护核验待审；不能视为经过批准的 Ground Truth。  
**代码**：`scripts/m01_stage_a_benchmark_builder_v001.py`  
**自动构建**：`.github/workflows/m01-stage-a-benchmark-builder-v001.yml`，本分支 GitHub Actions。  
**生产保护**：不更改任何 Story Shot、批准原图、V006/V007 视频、Video Index 或 main，不生成新的候选 MP4。

## 样本

- 7 个 PO 明确指出烛光偏移的镜头：N16 第一段、N18、N20 第一段、NEW-01、N21、A06、N24。
- 2 个 PO 已接受过烛光样式的镜头：N23、NEW-02（**样式接受不等于火焰像素标注已通过**）。
- 2 个没有明确可见烛火的日光负样本：N16 第二段、N17。负样本“无烛火”同样要逐帧人工确认。

- 源视频由 SHA-256 与 EDL 绑定，记录每张图原始 RGB SHA、FFmpeg 和人物检测模型身份。

构建后 `evidence/` 目录包含两张 JPEG 样本对照图、机器候选清单、Ground Truth 待审清单以及 33 张精度为 720×1280 的人物分割建议蒙版：

图像标记含义：蓝色为检测到的（非最终确认的）人物像素；橙色斜纹标识检测框覆盖但分割没有覆盖的不确定区域；玫红十字为历史试验/Style ROI 的未验证光源中心。**每个十字只是一条候选线索，不是定位正确的证明**。

## A1：把机器候选转为经过人工核对的基准答案

1. 逐样本确认是烛火而不是反光/窗外自然光/建筑纹理；分别标定每支火焰的真实中心/核心轮廓；把同一烛台的多火焰组织为唯一 `fixture_id`，不让 N18 重复识别。
2. 全帧核对人物、头发、衣服、背景过路人的遮罩，尤其 NEW-01、N21、N24；**不仅检查蓝色已有分割，还要检查遗漏的人**。
3. 对 N24 等检测失败镜头，保留 `NEEDS_CALIBRATION`，不得用猜测位置自动跳到通过。
4. 对 N16 第二段和 N17 的无烛火判定核对三帧，不能默认为所有画面均无烛火。
5. 经视觉确认后才生成独立 `GROUND_TRUTH_APPROVED` 资产、标注者/审核者、原图 SHA、每组光源 mask SHA 和人形 mask SHA，且应有冻结的人工验证测试用例。

## A2：工程验收（通过 A1 后才可开始）

比较检测输出和独立 Ground Truth，至少分别记录逐光源匹配误差/漏检/误检、人物 mask IoU 与漏保护率，以及无烛火负样本误触发率。阈值必须基于已冻结基准与实际审核决定，**不得用固定像素偏差或算法自身输出当正确答案**。

## 可复用引擎验收（不同于 S02-B）

Stage A 样本参与研发调试，不能充当跨场景“未见过的测试集”。后续必须使用独立从未参与参数调整的不同场景，考验新机位、遮挡、不同灯具、人物以及无火源失败拦截能力。S02-B 通过仅是必要条件，不是产品完成。

**任何 GitHub Actions SUCCESS 均只证明构建/机器自检成功；不表示烛火定位、人物 Ground Truth 或 M01 引擎得到 PO 批准。**
