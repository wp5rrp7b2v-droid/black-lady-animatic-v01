## 1. DESIGN PRINCIPLE

The new N21 design deliberately removes the visual burdens that repeatedly destabilized Candidate 01–08.

Therefore the next attempt should also reduce direct-reference pressure.

Candidate 09 will begin with:

`ONE DIRECT VISUAL REFERENCE ONLY`

No environment image is delivered directly in the first test.

Reason:

The previous threshold-environment reference successfully preserved scene language but also coexisted with the repeated tendency toward:

- monumental architecture;
- centered vanishing point;
- clear corridor geometry;
- entrance / arch as visual subject.

The redesigned N21 no longer needs to prove full doorway or entrance geometry.

The minimum test should therefore ask whether Work can build the required partial castle space from written shot authority while using a visual reference only for human naturalness.

## 8. FAILURE INTERPRETATION

If Candidate 09 fails because:

### A. Human bodies regress
Then the one-reference architecture itself failed.

### B. Environment drifts too far from the established castle
Then add ONE narrowly scoped environment reference in a future revision.

### C. Architecture remains monumental even without an environment image
Then the failure is not primarily caused by the existing threshold reference and should be handled at prompt / model behavior level.

### D. Crowd still forms a queue
Then revise blocking language before adding more visual references.

Do not react to one failure by immediately adding multiple reference images.
