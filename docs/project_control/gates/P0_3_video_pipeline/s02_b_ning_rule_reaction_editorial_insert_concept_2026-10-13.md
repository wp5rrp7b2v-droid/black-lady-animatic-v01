## 3. 新画面导演要求（概念层）

- 画幅：9:16 纵向；正式候选依既有规范以单张 PNG 为单位。
- 主体：宁秋水独自成为第一视觉主体；可读 3/4 侧脸，不正面直视镜头。
- 景别：近景/中近景；不是现有 N26 全景的数字放大或裁切。
- 表演：仍置身随人群前行的真实空间；听见尼尔说明后，目光出现细微停顿或转移，神情克制，无恐慌、夸张惊讶、指点、僵硬定格。
- 连续性：宁秋水服装、发型、年龄、面部、体态保持批准角色一致；手不插袋。背景仍是 CASTLE_ENTRANCE_INNER_LOBBY，不出现门外晴空、雨、关闭的大门、First Hall、壁炉或大楼梯。
- 视觉：暗调暖色、有限灯光、自然皮肤、干净而不提高整体亮度、物理一致的空间光影；禁止棚拍、高锐抠图感、过脏噪点。
- 不强制君鹭远或尼尔入镜，避免双人正面合影及群像拥挤；优先完整表达宁秋水的观察。

## 5. 最小验证门槛

### 关键工作假设
插入一张真正不同机位的宁秋水反应图，能在保留原语音与已批准 N25/N26 画面的条件下，使“雨天关门是夫人的要求”产生更清楚的叙事重心，并改善后半段的观看节奏。

### 最小测试
先只制作 **1 张独立 PNG 候选**（必须先完成 Scene Reference → Bundle 构建及 exact verification → Work）；通过 PO 静帧审批后，仅做 N25 → 临时反应插镜 → N26 的局部音画上下文试剪，与现有批准 S02-B V001 对应片段对比。

### PASS
1. 人物身份/服装、空间、方向、光色与邻镜连续；
2. 反应克制、与台词相关、不是肖像摆拍或同源裁切；
3. 原声连续，语义对位准确；
4. PO 在对比观看后认为**叙事清晰度与局部观感明显更好**。

### FAIL
身份漂移、场景断裂、情绪夸张、音画错位、与旧版无可察觉改进、或新图破坏 N26 行进节奏中的任一项。FAIL 时停止沿此策略扩展，不批量补图。
