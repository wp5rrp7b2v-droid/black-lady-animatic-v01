## 2. Editorial continuity

N24 establishes:

- Guang Yong has stopped with the group;
- Guang Yong looks toward entrance-side Neil and asks the question;
- Neil is off-screen;
- the group is still paused inside the entrance inner lobby.

A06 then interrupts with a static insert:

`THE CASTLE DOOR REMAINS OPEN`

A06 contains no character-position authority.

N25 resumes character action after the insert.

Therefore N25 does not need to visually reconnect to the door.

## 3. Narrative function

N25 must do two things:

1. answer the question with the rain-day rule;
2. move Neil from entrance-side / rear-side position back toward the front / deeper-interior leading position.

The answer must feel routine and understated.

## 4. Core shot concept

`CUT BACK FROM A06 TO NEIL MOVING PAST THE PAUSED GROUP TOWARD THE FRONT, ANSWERING WITHOUT TURNING BACK`

This creates a deliberate contrast:

- N24 = frontal Guang Yong question;
- A06 = static door insert;
- N25 = moving Neil response.

`NEIL IS MOVING TOWARD THE FRONT / DEEPER INTERIOR`

`HE ANSWERS WITHOUT LOOKING BACK`

- irregular spacing;

- no synchronized first step.
