Status:

`PRODUCT OWNER APPROVED / LOCKED`

## 1. Product Owner decision

The remaining orientation plan is revised.

Previous plan:

`FRONT → LEFT PROFILE → RIGHT PROFILE → BACK`

New locked plan:

`FRONT → LEFT PROFILE → REAR 3/4 → BACK`

The unexecuted `RIGHT PROFILE` board is cancelled from V001 scope.

Reason:

RIGHT PROFILE would largely duplicate information already represented by LEFT PROFILE, while a rear three-quarter view adds materially more useful information for crowd blocking, inward movement, side-back framing and identity continuity in Story Shots such as N21 / N23.

## 2. REAR 3/4 definition

Canonical orientation label:

`REAR_3Q`

Conceptual rotation sequence:

`FRONT 0° → LEFT PROFILE 90° → REAR_3Q approximately 135° → BACK 180°`

REAR_3Q is back-dominant, with a readable side silhouette.

It is not:

- a front three-quarter portrait;
- a deliberate over-the-shoulder face reveal;
- a mirrored RIGHT PROFILE substitute;
- a Story Shot pose.

The body is approximately 135° rotated from FRONT, naturally showing the back plus one side.
