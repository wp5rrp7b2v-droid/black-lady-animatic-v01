## 1. DESIGN OBJECTIVE

建立 Guest A–J 的匿名身份分型与风格来源，使后续 4 个方向板满足：

- 与《黑衣夫人》现有角色处于同一视觉世界；
- 10 人彼此可区分；
- 同一 Guest 四个方向保持服装、体型、发型与基础年龄感一致；
- 不复制苏小小、廖健、温卿雅、光勇等命名角色；
- 资产精度服务群像，不追求主角级脸部细节。

核心原则：

`STYLE CONTINUITY FROM APPROVED CAST / NEW ANONYMOUS IDENTITIES`

---

## 2. IDENTITY BUILD METHOD — LOCK PROPOSAL

不一次性自由生成 40 个独立人物。

采用：

`FRONT MASTER FIRST → LEFT PROFILE → RIGHT PROFILE → BACK`

### Stage 1｜FRONT BOARD
先建立 Guest A–J 的 10 个匿名身份。

FRONT Board 经 Product Owner 批准后，成为：

`PRIMARY IDENTITY + BODY + WARDROBE AUTHORITY FOR GUEST A–J`

### Stage 2–4｜TURNAROUND EXTENSION
LEFT / RIGHT / BACK 只能解释为：

`SAME TEN PEOPLE FROM ANOTHER VIEW`

不得重新设计：

- 性别；
- 年龄感；
- 发型；
- 身高 / 体型；
- 上装 / 下装；
- 鞋；
- 主要服装层次。

这一路径用于降低 40 个视图独立生成造成的漂移。

## 5. ANTI-COPY RULE

Automatic FAIL at FRONT identity review if any Guest reads as:

- “another Su Xiaoxiao”;
- “another Wen Qingya”;
- “another Liao Jian”;
- “another Guang Yong”;
- obvious face swap / costume swap of an existing named character.

The goal is:

`SAME WORLD / DIFFERENT PEOPLE`

not:

`NAMED CHARACTER VARIANTS`.

`A / B / C / D / E`

Bottom row:
`F / G / H / I / J`

The slot map must remain identical across all four boards.

Work should NOT be asked to render letter labels as image text.

Guest labels should be added deterministically after visual approval if formal labeling is required.

Reason:

`MODEL-GENERATED TEXT IS NOT IDENTITY AUTHORITY`

---

## 7. STANDARD ASSET POSE

All four boards use a neutral asset pose.

Required:

- natural upright posture;
- arms relaxed at sides;
- hands visible where the angle permits;
- no hands in pockets;
- no crossed arms;
- no dramatic gesture;
- no walking pose;
- no theatrical expression;
- full feet visible;
- neutral gaze consistent with body orientation.

Not T-pose.

The asset board should feel like a practical visual reference sheet, not a fashion lineup.

---

## 8. FOUR-VIEW ORIENTATION RULES

### FRONT
- torso / head front;
- neutral face;
- identity-establishment authority.

### LEFT PROFILE
- body approximately 90° left profile;
- head follows body;
- no turning back toward camera.

### RIGHT PROFILE
- body approximately 90° right profile;
- head follows body;
- no turning back toward camera.

### BACK
- full back;
- head neutral with body;
- no face reveal.

Orientation convention remains the existing project screen-facing convention.

---

## 9. FOUR-VIEW CONSISTENCY TEST

For every Guest A–J, later boards must preserve:

- gender;
- approximate age;
- height class;
- body mass / shoulder width;
- hair length / shape;
- garment layering;
- sleeve length;
- top hem / outerwear length;
- trousers / skirt category;
- shoe category;
- overall color family.

Allowed tolerance:

- small facial micro-detail differences;
- tiny fabric-fold variation;
- subtle natural posture variation.

Not allowed:

- hair length changes;
- clothing changes;
- body build changes;
- sex changes;
- age jumps;
- shoes changing category;
- jacket appearing / disappearing;
- skirt ↔ trousers switch;
- bag / strap appearing.

## 11. PROPOSED GENERATION SEQUENCE

Do not generate all four boards at once.

### Pass 1
`FRONT BOARD / EXACTLY 1 PNG`

Then Product Owner review.

If FRONT fails:
- fix identities before any side/back generation.

If FRONT passes:
- lock Guest A–J visual identities.

### Pass 2
`LEFT PROFILE BOARD / EXACTLY 1 PNG`

### Pass 3
`RIGHT PROFILE BOARD / EXACTLY 1 PNG`

### Pass 4
`BACK BOARD / EXACTLY 1 PNG`

Each pass is separately reviewable.

This keeps correction cost low and prevents propagating a bad identity base into all 40 views.

---

## 12. QUALITY TARGET

These are crowd assets, not hero character assets.

Priority order:

1. identity consistency;
2. wardrobe consistency;
3. body / silhouette consistency;
4. project style consistency;
5. clean full-body readability;
6. facial detail.

Do not spend production effort on cinematic expressions or hero-grade facial polish.
