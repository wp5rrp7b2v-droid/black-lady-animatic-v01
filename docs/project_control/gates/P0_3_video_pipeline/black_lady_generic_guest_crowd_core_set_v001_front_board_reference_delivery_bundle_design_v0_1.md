## 7. BOARD COMPOSITION CONTRACT

Canvas: `1536 × 1024`

Layout: `2 × 5`

要求：
- 十人统一摄影尺度；
- slot 间有足够空间；
- 人物不接触、不重叠、不裁切、不跨 slot；
- 身高/体型差异可直接比较；
- 整体为实用资产参考板。

Background:
`SIMPLE / NEUTRAL / LOW-DISTRACTION`

优先中性灰或暖灰、均匀可读照明。

禁止古堡、门、家具、室外风景、戏剧化电影光、强白棚拍感、时装摄影感。

`TEN ORDINARY ANONYMOUS ADULTS FROM THE SAME VISUAL WORLD`
