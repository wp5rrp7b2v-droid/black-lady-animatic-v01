# BLACK_LADY_GENERIC_GUEST_CROWD_CORE_SET_V001｜Asset Design V0.1

Status: `PRODUCT OWNER APPROVED / LOCKED`

Date: 2026-10-02

Asset family:

`PROJECT-LEVEL REUSABLE ANONYMOUS GUEST CROWD ASSET SET`

Purpose:

建立一组可在《诡舍·黑衣夫人》多人 Story Shot 中反复调用的固定匿名诡客资产，减少每个群像镜头重新随机生成人物导致的身份、服装、体型与风格漂移。

---

## 1. CORE STRUCTURE — LOCKED

V001 建立：

`10 FIXED ANONYMOUS GUESTS × 4 FULL-BODY ORIENTATIONS = 40 CONTROLLED VIEWS`

固定匿名身份：

- Guest A
- Guest B
- Guest C
- Guest D
- Guest E
- Guest F
- Guest G
- Guest H
- Guest I
- Guest J

这 10 人不是主要剧情角色，不替代苏小小、廖健、温卿雅、光勇等已有角色资产。

---

## 2. FOUR-BOARD OUTPUT MODEL — LOCKED

正式目标为四张统一参考资产板，每张包含同样 10 人：

### Board A｜FRONT
`Guest A–J / full-body front`

### Board B｜LEFT PROFILE
`Guest A–J / full-body left profile / approx 90°`

### Board C｜RIGHT PROFILE
`Guest A–J / full-body right profile / approx 90°`

### Board D｜BACK
`Guest A–J / full-body back`

四张板必须维持 A–J 的一一对应关系。

---

## 3. IDENTITY PRECISION

匿名诡客不要求主角级精度。

必须稳定：

- 同一 Guest 四个视角仍可判断为同一人；
- 服装四面一致；
- 体型比例一致；
- 发型轮廓一致；
- 基础年龄感一致；
- 鞋型 / 裤装 / 外套等大轮廓不漂移；
- 视觉语言属于《黑衣夫人》既有写实人物世界。

不要求：

- 主角级面部细节；
- 复杂表情；
- 剧情性动作；
- 高强度身份特写能力。

---

## 4. POPULATION DIVERSITY

10 人必须具有足够区分度，避免形成模板 NPC。

### Gender distribution — HARD LOCK

`6 FEMALE + 4 MALE`

该比例属于 V001 的正式人口结构，不得在后续生成中自由改写。

允许并鼓励差异：

- 性别比例固定为 6 女 / 4 男；
- 年龄感轻微差异；
- 高矮差异；
- 胖瘦差异；
- 发型差异；
- 上装 / 外套轮廓差异；
- 裤装 / 鞋型差异；
- 服装明暗节奏差异。

共同边界：

- 现代普通成年人；
- 同一故事世界；
- 同一写实度；
- 不过度时尚；
- 不过度职业化；
- 不戏剧化 / cosplay 化。

---

## 5. STYLE ORIGIN

风格不是自由发散。

后续 Style / Identity Reference Design 应从已经稳定的主要诡客角色体系中抽取视觉语言，例如：

- 苏小小；
- 廖健；
- 温卿雅；
- 光勇；
- 必要时其他已批准角色。

允许继承：

- 写实程度；
- 成人比例；
- 服装时代感；
- 材质表现；
- 色彩节奏；
- 普通人真实感；
- 头发 / 皮肤 / 布料的项目统一语言。

禁止复制：

- 主要角色脸；
- 主要角色完整服装；
- 主要角色身份特征；
- 主要角色固定剧情姿态。

原则：

`SAME VISUAL WORLD / NEW ANONYMOUS IDENTITIES`

---

## 6. PERMANENT PROHIBITIONS

该资产族永久禁止：

- backpack；
- shoulder bag；
- crossbody bag；
- handbag；
- luggage；
- travel bag；
- expedition equipment；
- 大型夸张配饰；
- 强制服 / 团体制服化；
- 时尚大片摆拍；
- cosplay / 舞台感；
- 过锐人物边缘 / 抠图感。

这些禁止项后续进入所有使用该资产的 Bundle / Work 指令。

---

## 7. BOARD PRESENTATION

四张 Board 是资产板，不是 Story Shot。

要求：

- 中性、低干扰背景；
- 全身完整可见；
- A–J 清楚对应；
- 人物尺度尽量统一；
- 不使用剧情环境；
- 不形成正式群像构图；
- 不暗示 N21 / N23 的具体人物站位；
- 不作为机位或 Story Shot blocking authority。

---

## 8. PROJECT-LEVEL AUTHORITY SCOPE

Authority scope：

`BLACK_LADY PROJECT-LEVEL REUSABLE CROWD IDENTITY / BODY / WARDROBE CONTINUITY`

允许控制：

- 匿名诡客 A–J 身份连续性；
- 四向身体外观；
- 体型 / 发型 / 服装连续性；
- 群像中的普通现代成人视觉语言；
- Crowd Story Shot 中可复用的人物选择。

不得控制：

- 主要角色身份；
- Story Shot 最终构图；
- 单镜头 camera；
- crowd blocking；
- 具体剧情动作；
- 场景环境；
- 光线；
- N21 / N23 的镜头叙事优先级。

本设计明确为项目级复用，不得后续缩窄为 N21-only 或 N23-only。
