## 1. Purpose

This patch clarifies the governance level of S02-B Director Shot Design V0.3.

From N21 onward, the project locks:

- narrative function;
- audience-retention purpose;
- continuity requirements;
- cinematic quality principles;
- visual-tone continuity.

It does **not** pre-lock the exact composition of every N-shot.

Concrete choices such as shot size, camera height, camera direction, foreground/background placement, occlusion, body pose, eyeline, POV/OTS use and exact character positions are decided at the individual Director Shot Design stage according to:

- source story / audio semantics;
- preceding and following shots;
- scene continuity;
- available approved references;
- actual candidate-image quality.

If earlier V0.3 wording appears to prescribe one exact composition, treat that wording as:

`PROVISIONAL DIRECTOR EXAMPLE / NON-BINDING UNTIL NODE-LEVEL DIRECTOR DESIGN`

Node function remains authoritative.

## 2. Eight locked high-level rules

### Rule 1｜Narrative value

Every new Story Shot must add meaningful value beyond the previous image.

Valid added value includes:

- information;
- emotion;
- spatial change;
- character relationship;
- risk cue;
- question;
- narrative progression.

A shot is not justified merely by showing the same event from another angle.

### Rule 2｜Effective visual change

Adjacent shots should create meaningful visual variation and should not repeatedly preserve the same shot scale, camera relation, character arrangement and body state.

As a working principle, aim to change at least two meaningful visual dimensions when appropriate.

This is a director guideline, not a mechanical formula.

Story clarity remains the higher authority.

### Rule 3｜Characters must feel inside the story

Characters should appear to be caught during ongoing action, observation or reaction rather than posed for a still photograph.

Avoid:

- lineup staging;
- publicity-photo staging;
- repeated static standing;
- synchronized body states without story reason.

Prefer natural differences in:

- movement phase;
- balance;
- attention;
- eyeline;
- body orientation;
- interpersonal spacing.

### Rule 4｜Spatial depth

Use depth, overlap, occlusion, foreground/background relationships and architectural framing when they strengthen the scene.

These devices are not mandatory in every image.

The locked requirement is to avoid unnecessary flatness and make characters feel embedded in a real space.

### Rule 5｜Ning Qiushui remains the observational anchor

Across the sequence, the audience should primarily experience important information through what Ning notices, registers and judges may matter.

This does not require Ning to appear in every shot.

POV, OTS, reaction, eyeline and object/space inserts are optional tools, not mandatory templates.

### Rule 6｜Character functions must remain differentiated

Characters should appear when they serve the current narrative beat.

Baseline:

- Ning Qiushui = primary observational anchor;
- Jun Luyuan = audience-entry / human-scale companion;
- Neil = guide / information source where required by the source;
- other participants = used according to the immediate story function.

Do not insert characters merely to maintain screen presence.

### Rule 7｜Concrete composition is decided later

V0.3 locks node function and overall cinematic principles.

It does not lock in advance:

- exact shot size;
- exact camera angle;
- exact camera height;
- exact foreground/midground/background assignment;
- exact occlusion pattern;
- exact body action;
- exact face direction;
- mandatory POV / OTS.

These decisions belong to each node's Director Shot Design.

### Rule 8｜Color / look continuity

Images from the same continuous time and space must feel as though they belong to one visual world.

Generation-stage control must cover:

- color-temperature family;
- exposure;
- black level;
- saturation;
- contrast;
- principal light direction.

For the current castle interior baseline:

- warm low-key practical-light family;
- natural skin tones, not orange;
- readable texture in dark hair, clothing and stone;
- restrained low-to-moderate saturation;
- moderate cinematic contrast;
- broadly continuous light direction across adjacent shots.

Continuity does **not** mean every image must have identical grading.

Story- and space-motivated changes are allowed, for example:

- nearer the entrance = naturally brighter / cooler;
- deeper interior = naturally darker / warmer or lower-key.

The test is:

`DO THESE IMAGES BELIEVABLY OCCUR IN THE SAME CASTLE AND THE SAME CONTINUOUS PERIOD?`

Gross random shifts between orange-heavy, neutral-gray, over-bright and crushed-dark renders are not acceptable.

## 3. Core review test

For every new shot from N21 onward, Director Review should primarily ask:

1. What does this image add?
2. What meaningfully changes from the previous image?
3. Does it look like the story is happening, or like characters are waiting to be photographed?
4. Does it still belong to the same visual world as the adjacent shots?

These four questions are the high-level review baseline.
